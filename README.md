# M. Sina Heidaripour — personal site

Static HTML/CSS/JS site (no build step, no backend) hosted on GitHub Pages at <https://sinahdp.github.io/>.

- `index.html` — all sections (hash-routed: `#/overview`, `#/projects`, `#/skills`, `#/education`, `#/contact`)
- `style.css` — dark theme, fixed sidebar on desktop, bottom tab bar on mobile
- `script.js` — section switching and project filters
- `assets/Sina_Heidaripour_CV.pdf` — downloadable CV

Pages setting: Settings → Pages → Deploy from a branch → `main` / `/ (root)`.
